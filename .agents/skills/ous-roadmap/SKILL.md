# Ously Roadmap (ous-roadmap)

This skill focuses on the "What" and "Why" of the Ously ecosystem. It is used to maintain the high-level product vision and ensure that all technical work aligns with business objectives.

## 🚀 Workflows

### 1. New Feature Definition
- Brainstorm and define high-level features.
- Identify target users and value propositions.

### 2. EPIC Creation
- Create issues with the `[Epic]` prefix.
- Use GitHub Native Issue Type: `Epic`.
- **Mandate**: Epics should describe a complete user outcome or technical milestone.

### 3. Roadmap Review
- Audit the current set of Open Epics.
- Prioritize features based on business impact.

## 🛠 Project Standards
- **Issue Types**: Always use native `Epic` types.
- **Title Convention**: `[Epic] <Feature Name>`.
- **Context**: Every Epic must explain its business value and high-level scope.
